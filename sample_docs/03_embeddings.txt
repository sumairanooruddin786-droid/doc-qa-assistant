An embedding is a list of numbers, called a vector, that represents the meaning of a piece of text. Sentence-transformer models such as all-MiniLM-L6-v2 turn a sentence into a vector of 384 numbers. Texts with similar meaning end up close together in this vector space, even if they use different words. For example, the sentences "How do I reset my password?" and "I forgot my login credentials" have very different words but nearby vectors. Closeness is usually measured with cosine similarity, which compares the angle between two vectors and returns a value near 1 for similar meaning. Cosine distance is simply one minus cosine similarity, so a smaller distance means a closer match. Semantic search differs from keyword search because keyword search only matches exact words, while semantic search matches meaning and handles synonyms and paraphrases.
