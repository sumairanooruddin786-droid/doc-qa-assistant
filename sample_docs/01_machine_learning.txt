Machine learning is a field of artificial intelligence where systems learn patterns from data instead of following hand-written rules. In supervised learning, a model is trained on labelled examples, such as emails marked spam or not spam, and learns to predict labels for new data. In unsupervised learning, the model finds structure in unlabelled data, for example by clustering similar customers together. Overfitting happens when a model memorises its training data and performs poorly on new data. To reduce overfitting, practitioners use more data, regularisation, and a separate validation set. Model quality is measured with metrics such as accuracy, precision, recall and F1 score. Good data preparation, including cleaning, normalising and splitting data, usually matters more than choosing a fancy algorithm.
