Retrieval-Augmented Generation, or RAG, combines a search step with a language model. First the system retrieves the document chunks most relevant to the user question. Then it places those chunks in the prompt as context and asks the language model to answer using only that context. RAG reduces hallucinations because the model is grounded in real source text instead of relying on memory alone, and it lets answers cite their sources. It also lets a system use private or recent documents without retraining the model. Prompt engineering matters in RAG: zero-shot prompts give only the instruction, few-shot prompts add worked examples that show the desired format, and role-based prompts assign a persona such as a technical document analyst to shape tone and structure. If retrieved chunks are poor, the answer will be poor, so retrieval quality is the foundation of a good RAG system.
